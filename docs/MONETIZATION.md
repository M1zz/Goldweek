# Goldweek 유료화 설계 (2.4.0~)

## 원칙

**쉬는 습관은 무료, 계획과 자동화는 Pro.**

무료만으로도 "연차를 놓치지 않고, 제때 쉬는" 생활이 되어야 한다. 그래야 사람이 남고, 남은 사람이 산다.
Pro는 "없어도 되지만 있으면 시간과 머리를 아껴 주는 것"에 둔다. 써 본 사람이 기꺼이 돈을 내는 지점이다.

나누는 질문 하나: **이 기능이 없으면 휴가를 놓치거나 기록이 틀리는가?**
그렇다면 무료다. 그렇지 않고 더 잘 쉬게 해 주거나 손을 덜어 주는 기능이면 Pro다.

## 무료: 건강하게 쉬는 데 필요한 것

| 기능 | 무료인 이유 |
|---|---|
| 연차·반차·반반차·시간 단위 기록, 남은 연차 | 앱의 바닥. 이게 막히면 앱이 아니다 |
| 근무 형태 (고정·파트타임·교대), 요일별 근무 시간 | 계산이 틀리면 신뢰가 무너진다 |
| 42개 나라 공휴일, 내 공휴일·방학, 휴가 불가 기간 | 정확성 |
| 올해 추천 전부 보기 + 3개 등록 | 앱의 "아하" 순간. 맛은 충분히 보여 준다 |
| 쉬는 간격·번아웃 안내, 알림, 위젯 | 건강하게 쉬도록 돕는 핵심 |
| 직접 만든 휴가 종류 (이름·색·순서), 종류별 합계 | 기록의 정확성 |
| 휴가 내역 사진으로 가져오기 | 처음 시작할 때 진입 장벽을 낮춘다 |
| iCloud 백업·복원, 타임머신 | 데이터 안전은 돈으로 막지 않는다 |
| 가족 일정 공유 | 공유받은 사람이 새 사용자가 된다 |

## 트림: 플러스 · 프로 · 패밀리

자동차 트림처럼 위로 갈수록 앞 트림을 모두 포함한다. **주력은 프로**다.
플러스는 프로를 싸 보이게 하는 자리이고, 패밀리는 둘 이상이 쓰는 집에서 프로 두 개보다 싸게 만든다.

| 트림 | 누구 | 더해지는 기능 | 언제부터 |
|---|---|---|---|
| **플러스** | "알아서 짜 줘" | 최적 연간 플래너 | 원래 Pro |
| | | 추천 무제한 등록, 지난해·다음 해 추천 | 원래 Pro |
| | | 캘린더 앱으로 보내기 | 원래 Pro |
| **프로** | 규칙이 복잡한 사람 (교사·교대·보상휴가) | 보너스 연차 | 원래 Pro |
| | | **종류별 연간 한도·넘겨 쓰기** | **2.4.0** |
| | | **학교 달력 가져오기** (사진·PDF·붙여 넣은 글) | **2.4.0** |
| | | 캘린더 자동 감지·가져오기 | 원래 Pro |
| **패밀리** | 맞벌이·자녀가 있는 집 | 프로 전부를 가족 최대 6명이 함께 (App Store 가족 공유) | 2.4.0 |
| | | 함께 쉬기 — 가족 모두 쉬는 날(3일 이상)·한 사람만 연차 1~2일 내면 되는 날 (가족 탭 맨 위) | 2.4.0 |
| | | 가족 기념일을 가족이 같이 보고, 그날 누가 일하는지·내 휴가 내기 | 2.4.0 |

함께 쉬기는 공유받은 일정으로 센다: 각자 나라의 기본 주말·공휴일 + 공유한 종일 휴가 (반차·시간 단위는 쉬는 날 아님).
기념일은 CloudKit 새 기록 종류 `SharedAnniversary` 로 공유한다 — 운영 환경에 스키마를 배포해야 하고,
배포 전에도 휴가 공유는 따로 저장하므로 깨지지 않는다.

가족 일정 **보기 공유**는 계속 무료다 (공유받은 사람이 새 사용자가 된다). 패밀리는 "보기"가 아니라 "같이 계획하기"를 판다.

2.4.0 전 페이월에 "iCloud 백업 = Pro"라고 적혀 있었지만 실제로는 무료였다. 백업은 무료로 두기로 하고 비교표에서 뺐다.

## 가격

| 상품 | ID | 미국 | 한국 | 가족 공유 |
|---|---|---|---|---|
| 플러스 연간 | `com.Ysoup.LeaveWise.plus.annual` (새로 — plus.yearly 는 이미 쓰인 ID) | 9.99 USD | 14,000원 | 끔 |
| **프로 연간** (기본 선택, 7일 무료 체험) | `com.Ysoup.LeaveWise.pro.yearly` | 19.99 USD | 29,000원 | 끔 |
| 프로 평생 | `com.Ysoup.LeaveWise.pro` (기존, ID 그대로) | 49.99 USD | 69,000원 | 기존 설정 유지 |
| 패밀리 연간 (7일 무료 체험) | `com.Ysoup.LeaveWise.family.yearly` (새로) | 29.99 USD | 44,000원 | **켬** |

- **월간 상품은 두지 않는다.** 연차 계획은 연초에 한 번 몰아서 한다 — 월간이 있으면 1월에 한 달 내고
  한 해 계획을 다 짠 뒤 해지한다. 연 단위만 판다.
- 트림 간격을 10달러로 고르게 둔다. 플러스 → 프로는 "10달러 더 내고 다 받기", 프로 두 개(39.98) > 패밀리(29.99)라
  둘 이상이면 패밀리가 이득이다.
- 평생은 프로에만, 연간의 약 2.5배. 구독이 싫은 사람의 선택지이자 가격 기준점.
- 페이월에는 연간 가격을 12로 나눈 월 가격("한 달 ₩X꼴")을, 패밀리는 "한 사람당 한 달 ₩X꼴"(6명 기준)을 보여 준다.
- 구매력이 낮은 나라(인도네시아·베트남·태국·튀르키예·브라질·러시아)는 자동 환산보다 40~50% 낮게 직접 정한다.
- 구독 그룹 "Goldweek" 하나에 레벨: 패밀리 1, 프로 2, 플러스 3 — 올리면 즉시 바뀌고 남은 기간은 애플이 정산한다.
- App Store 가족 공유는 상품에서 한 번 켜면 끌 수 없다. 패밀리 상품에서만 켠다.
  가족 구성원은 `Transaction.ownershipType == .familyShared` 로 들어오며 권한은 구매자와 같다.

### 수익 가정 (검증 전)

설치 1만 건, 첫해 기준. 전환율·비율은 가정이고 2.4.0 배포 뒤 `purchase_plan`·`paywall_view` 로 고친다.

| | 2.99/7.99 단일 Pro | 트림 (위 가격) |
|---|---|---|
| 유료 전환율 | 3.0% | 2.2% (비싼 만큼 낮춰 잡음) |
| 상품 비율 | 연간 60 · 평생 40 | 플러스 15 · 프로 연간 45 · 프로 평생 15 · 패밀리 25 |
| 결제자 1명당 순매출 (수수료 15% 뒤) | 약 4.2 USD | 약 21.6 USD |
| 첫해 순매출 | 약 1,270 USD | 약 4,750 USD |

전환율이 1.0%까지 떨어져도 약 2,160 USD로 단일 Pro보다 많다. 1.0% 아래로 가면 가격을 한 단계 내린다.

## 기존 사용자

- 평생 구매자(4.99 USD에 산 사람 포함)는 **프로** 트림이다 (상품 ID 그대로). 패밀리 기능은 포함하지 않는다.
- 2.4.0 전에 설치한 무료 사용자는 **2.4.0에서 새로 Pro가 된 기능을 계속 무료로 쓴다** (`ProFeature`, `ProManager.has(_:)`).
  - 판별 1: 2.4.0을 처음 켤 때 이미 온보딩을 마친 기기 (`proLegacyFreeFeatures`, 한 번 정하면 바뀌지 않는다)
  - 판별 2: 앱을 지웠다 다시 설치한 경우 `AppTransaction.originalAppVersion`(최초 다운로드 빌드 번호)이 11 이하
  - 설정의 "이용 중인 버전" 아래에 "계속 무료" 안내를 보여 준다
- 원래부터 Pro였던 기능은 이 혜택과 상관없이 `isPro`로 판단한다.

## 새 기능을 만들 때

1. 위 질문으로 무료인지 Pro인지 정한다.
2. 무료였던 기능을 Pro로 옮긴다면 `ProFeature`에 케이스를 넣고 `has(_:)`로 막는다. 기존 사용자를 보호하기 위해서다.
   처음부터 Pro인 새 기능은 `isPro`로 막는다.
3. 페이월 비교표(`PaywallView.featuresSection`)와 온보딩 Pro 목록(`ProShowcasePage.proFeatures`)을 실제 동작과 맞춘다.
