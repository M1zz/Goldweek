❓Questions fréquentes

Dans Réglages, vérifiez le mois de début de votre année de congés et votre nombre total de jours de congés annuels. Les demi-journées (0,5) et les quarts de journée (0,25) sont déduits automatiquement. Les absences qui ne sont pas décomptées, comme les arrêts maladie, les congés exceptionnels ou les déplacements professionnels, ne modifient pas votre solde. Si le problème persiste, écrivez-nous.
Les congés annulés ne s’affichent pas dans le calendrier. Ouvrez l’entrée dans l’onglet Ajouter et vérifiez son statut. Installer la dernière version de l’app peut aussi régler le problème.
Rendez-vous dans la section Congés bonus, en bas de l’onglet Ajouter. Choisissez un type (récupération, congé de récompense, congé de ressourcement…), indiquez le nombre de jours et, si vous le souhaitez, une date d’expiration. Les congés bonus sont suivis à part de vos congés annuels.
Touchez Restaurer l’achat en bas de l’onglet Réglages. L’achat est restauré avec le compte Apple connecté à l’App Store. Si cela ne fonctionne pas, envoyez-nous un e-mail.
Vos données sont stockées sur votre appareil : supprimer l’app les efface définitivement. Activez la Sauvegarde iCloud pour en garder une copie que vous pourrez restaurer plus tard.
Oui. Dans Réglages, ouvrez Jours fériés et vacances : vous pouvez y ajouter vos propres jours fériés ou masquer n’importe quel jour férié par défaut.
Goldweek intègre les jours fériés de 42 pays. Choisissez votre pays (et votre État ou votre région quand les jours fériés varient) dans Réglages : le calendrier se met à jour aussitôt. Votre pays n’est pas dans la liste ? Ajoutez vous-même ses jours fériés, ou demandez-nous de le prendre en charge en envoyant un avis depuis l’app.
